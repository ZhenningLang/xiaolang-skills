# 头脑风暴流程：机制与假设

状态：草案，待作者 review。流程图见 [brainstorm-flow.png](brainstorm-flow.png)。

每个机制都当成待验证的假设。考题测不出作用的机制，从默认流程删除。

## 判定规则（跑之前先定，跑完不改）

- **噪声线**：同一配置同一道题至少重复跑 3 次。差异小于重复波动，算没有作用。
- **有用**：多数考题上超过噪声线，并且符合下面任一条：作者计分的点子有来自它的，或者它要防的失败确实少了。
- **删除**：达不到「有用」，或者效果抵不过增加的成本。
- **防刷分**：独有机制数不能单独作为通过依据。怪点子能刷高这个数，必须配合作者计分。

阈值的具体数字等噪声线测出来再定。

## 什么点子算分

作者判断三件事，三件都满足才计分：

1. **没想到**：看这道题之前没想到过。
2. **成了会在乎**：假设它成了，作者在乎这个结果。这一问先不管能不能成。
3. **说不出致命原因**：作者说不出它一定不成的理由，比如违反硬约束或已知事实。

「想不想试」只记录，不计分。这个分数决定流程怎么改，如果把「想试」算进去，流程会被稳妥偏好带着走，最怪的压力升级也最容易被误删。

这条规则本身也是假设，有两个检查：

- **混入明显不行的点子**：如果它们也常常计分，规则就要改。
- **抽 2 条真试**：在作者的真实问题上，从标了不想试但计了分的点子里抽 2 条真试。只抽 agent 能低成本做出原型的点子，没有就跳过。

## 公共指标

| 指标 | 含义 | 谁来算 |
|:---|:---|:---|
| 独有机制数 | 按机制去重后，不同机制的个数 | 固定的去重程序 |
| 基线外比例 | 不在常见点子清单里的机制占比 | 固定的去重程序 |
| 两两重合率 | 任意两个 agent 的机制重合比例 | 脚本 |
| 计分命中 | 作者计分的点子来自哪个配置、哪一步 | 作者判断，脚本还原来源 |
| 想试比例 | 作者标为想试的点子占比，只记录，不计分 | 作者判断 |
| 血统 | 每个点子记录模型、方法、卡片、轮次、压力级别 | 脚本，流程全程记录 |
| 成本 | token 和耗时 | 脚本 |

## 机制表

题型说明见下一节。

| 机制 | 想达到的目的 | 要验证的假设 | 对照组 | 题型 | 判定没用的信号 | 已有依据 |
|:---|:---|:---|:---|:---|:---|:---|
| 按机制去重 | 让所有指标可信，并产出禁区 | 程序判定和作者人工判定足够一致，换个模型判结果也稳定 | 作者标注的样本 | 任意 | 一致性低：所有指标都不可信，要先修 | 暂无 |
| 互盲选角度 | 收集阶段不被单一视角定义问题 | 互盲选出的角度更广，产出更多不同卡片 | 主 agent 自己定角度 | 开放题 | 卡片覆盖没有差别 | 推论，无实验 |
| 随机材料 | 给每个 agent 不同的背景知识 | 随机子集比全量相同材料、无材料产出更多独有机制 | 无材料；全量；30%；50% | 开放题、染色题 | 差异在噪声内；或点子不用分到的卡片 | 作者设想；Hope 2017 反证 |
| 调研自由 | 让 agent 自己补信息 | 允许调研比只用分到的材料更好 | 禁止调研；先想后查；不限 | 开放题 | 调研多花的成本换不来计分命中 | 暂无 |
| 互盲生成 | 防止互相锚定 | 互盲比能看到前人结果的串行产出更多独有机制 | 串行可见 | 开放题 | 差异在噪声内 | Diehl & Stroebe 1987，人类实验 |
| 原始问题不预定义 | 防止问题定义错了全盘皆错 | 错误前提题上，拿原始问题的 agent 更常质疑前提 | 主 agent 改写后的问题 | 错误前提题 | 质疑率没有差别 | 图书馆题有 2 个 agent 主动质疑，未对照 |
| 分配不同方法 | 改变思路路径 | 不同方法比同方法、无方法的重合率更低 | 无方法；同方法；不同方法 | 开放题 | 重合率差异在噪声内 | 图书馆题有迹象，但方法和调研混在一起 |
| 三步法 | 单个 agent 内部逼出差异 | 列标题、求异改写、再展开，比直接出 10 个更分散 | 直接出 10 个 | 开放题 | 基线外比例没有提升 | Meincke 2024，LLM 实验 |
| 多模型 | 不同模型提供不同背景 | 多模型混合比单模型独有机制更多，每家都有独有贡献 | 单模型；六家混合 | 开放题 | 某家没有独有贡献就去掉它；整体差异在噪声内就默认关闭 | Terwiesch 2026 与 Jiang 2025 结论相反 |
| 预判同伴 | 让 agent 主动避开大家都会想到的 | 先写下同伴会写什么并划掉，能降低重合率 | 不加这一步 | 开放题 | 重合率没有变化 | 我的假设，无依据 |
| 基线与撞车退回 | 把点子推出常规区，并避免提前看示例被带偏 | 退回后换出的点子跳出基线，并且能计分 | 不退回；禁区放在生成前 | 开放题 | 换出的点子从未计分 | 示例固着，人类实验 |
| 常规多轮与延后拆解 | 拆解的好处和不限制创新都要 | 第一轮不拆、第二轮才按拆法指派，优于提前拆和不拆 | 提前拆；不拆；延后拆 | 开放题、可拆解题 | 延后拆不优于不拆 | Dennis 1996；作者的担心 |
| 枯竭后压力升级 | 枯竭之后才是原创区 | 枯竭后的点子在计分点子中占比不低于枯竭前 | 枯竭即停；只说「再想想」 | 开放题 | 枯竭后的点子很少计分 | Beaty & Silvia 2012，人类实验；作者判断 |
| 压力四级各自 | 每级改变不同的东西 | 每一级都有新机制，并有点子计分 | 去掉该级 | 开放题、窄题 | 某一级没有贡献就删这一级 | 作者判断，无实验 |
| 组合 | 把碎片拼成完整方案 | 跨子问题拼接的方案，计分率高于单个点子 | 不组合 | 可拆解题 | 计分率没有更高 | 文章流程，无 LLM 实验 |
| 新评委打分 | 把更值得看的排在前面，只排序不删除 | 新评委的排序比生成者自评更接近作者计分，并能认出事先放入的好坏样本 | 生成者自评；同模型评委；跨模型评委 | 任意 | 排序和作者计分不相关：不按分数排，改按方向分组 | Si 2024；Berg 2016 |
| 试错方案 | 把点子变成可做的动作 | 作者看完方案能直接决定做不做 | 只给点子 | 真实问题 | 作者认为方案没有帮助 | 作者判断 |

## 需要的题型

| 题型 | 用来暴露什么 |
|:---|:---|
| 开放题 | 发散能力的主战场 |
| 错误前提题 | 问题本身问错时，流程能不能发现 |
| 染色题 | 材料里放一张带明显特征的卡片，追踪点子是否真的用了它 |
| 可拆解题 | 拆解和组合是否有用 |
| 窄题 | 解空间很小时，压力升级是否只产生怪点子，停止条件是否生效 |
| 真实问题 | 作者自己有判断力的问题，看最终结果能不能用 |
| 注入题 | 材料里放恶意指令，确认 agent 不会照做 |

## 不当假设的工程约束

这些不进考题，直接执行：

- 随机分配由脚本完成。模型自己随机不可靠，暗号实验三个暗号都以 Q 开头。
- agent 只读，只能写自己的目录。
- 用多模型前提示外发风险。
- 去重只合并，不判好坏。被合并的说法可以展开查看。
- 排名只排序，不清理。呈现给作者的条数必须等于去重后的条数，由脚本核对。

## 测试顺序

1. **按机制去重**：它不可信，后面的数字都不可信。
2. **生成阶段**：互盲、方法、三步法、材料、调研、模型。
3. **推出常规区**：退回、多轮、拆解、压力升级。
4. **取舍阶段**：组合、评委、试错。

## 未决问题

- 所有点子都给人看，要读多少条还没测。一次完整流程去重后的条数，等第一次真实运行才知道。
- 机制之间有交互。比如放开调研可能抵消随机材料的作用，所以要从完整流程里逐个去掉，也要从基线逐个加入。
